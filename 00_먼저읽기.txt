돌봄지음 호남 v2.7 · 현장점검 + 기관 결제신청 통합 시험본

[중요]
- 현재 운영 careindex-v2 브랜치나 Firebase 기관자료는 자동 변경되지 않습니다.
- GitHub의 dolbom-v25-test 시험 브랜치에 압축을 푼 '프로그램 폴더 안의 파일들'을 업로드합니다.
- Netlify는 GitHub 시험 브랜치의 변경을 감지해 자동으로 Branch deploy 합니다.
- 먼저 관리자 화면에서 전체 기관 DB CSV 백업을 보관하세요.
- 본 버전은 보호자용 8개 영역 29개 확인 현황(요양원/요양병원)과 관리자 현장점검·공개 승인 기능이 있습니다.
- 결제창은 기관 계정만 볼 수 있습니다. 무통장입금 신청을 저장하고 관리자가 입금을 수동 확인합니다.
- 카드번호 입력/카드승인/PG 자동결제/세금계산서 자동 발행/환불 자동 처리는 없습니다. 실제 결제창은 PG 승인 후 연동해야 합니다.
- 단지 신청을 접수했다고 기관이 홍보 검색에 공개되지 않습니다.

[서버 설정 확인]
기존 FIREBASE_SERVICE_ACCOUNT_JSON, FIREBASE_STORAGE_BUCKET, KAKAO_REST_API_KEY, KAKAO_CLIENT_SECRET, KAKAO_REDIRECT_URI가 연결된 환경인지 확인하세요.
추가 필수 변수 DOLBOM_AD_RATES_JSON: 기관별 월 홍보료 숫자만 포함하는 JSON입니다. 값을 공개 GitHub에 업로드하지 마세요.
예시는 이 파일에 넣지 않았습니다. 실제 금액은 운영자 판단에 따라 Netlify 환경변수에서 관리합니다.
결제 기능의 관리자 검토·PG 계약·세금 및 환불정책·전자상거래 고지·개인정보 법적 검토는 실제 출시 전에 별도 확인해야 합니다.

[운영 전 권장]
현재 프로그램은 Netlify의 production 이외 환경에서 쓰기 요청을 차단합니다. 시험용 Branch Deploy가 운영 Firebase와 연결되어도 저장·입금확인 등의 요청이 거절되도록 설계했습니다. 이를 풀지 않은 채 시험하세요. 테스트는 오프라인 미리보기에서 진행하세요.
