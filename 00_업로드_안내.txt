케어인덱스 호남 v2.1 — GitHub 업로드 전용

1. ZIP을 다운로드해 '모두 압축 풀기'를 누릅니다.
2. 압축을 푼 폴더를 열고, 그 안에 보이는 site / netlify / firebase / scripts / tests 폴더와 netlify.toml / package.json / README 파일을 모두 선택합니다.
3. GitHub 업로드 화면의 큰 사각형 영역에 선택한 항목들을 끌어다 놓습니다. ZIP 파일 자체나 겉 폴더를 올리지 마세요.
4. 업로드 파일 목록에 반드시 site/index.html, netlify/functions/kakao-start.mjs, netlify/functions/kakao-callback.mjs, netlify/functions/api.mjs, netlify.toml이 있어야 합니다.
5. careindex-v2 브랜치가 맞는지 확인한 뒤 Commit changes를 누르세요. main은 바꾸지 않습니다.
6. Netlify에 연결하는 작업은 별도로 진행해야 하며, 지금 업로드만으로 카카오 로그인이 바로 되지는 않습니다.

보안: 실제 Firebase 서비스 계정 JSON이나 카카오 클라이언트 시크릿은 이 ZIP에 넣지 않았습니다. 공개 GitHub에 비밀키를 절대 올리지 마세요.
