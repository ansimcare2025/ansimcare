[변경된 코드]
1) netlify/functions/_shared/profile-policy.mjs (신규)
   - 기관 수정요청은 변경 필드만 보관. 공식 식별번호·자료출처·계약 상태·관리자 UID는 수정대상에서 제외.
   - 관리자가 승인할 때 제출 당시의 기존 값과 현재 값을 다시 비교: 중간 변경 시 409 충돌로 승인 차단.
2) netlify/functions/api.mjs
   - submit_profile은 수정분만 저장, 본문·사진은 비공개 요청. 관리자 최종 승인 전 공개DB 변경 없음.
   - submit_material: 기관이 비식별 참고내용을 비공개로 전달 (문서 첨부 기능 아님).
   - review_material: 관리자는 내용 확인/보완요청만 처리; 공개DB 불변.
   - review_request: 관리자만 처리, 독립 확인 여부와 10자 이상 검증근거 요구.
   - 구형 변경 양식 요청은 신규 양식으로 다시 제출해야 승인 가능(기존정보 보호).
   - 동일기관 대기 요청 수 상한: 프로필 5건, 참고자료 10건.
3) site/index.html · site/app.js · site/ui-fixes.css
   - 기관: 현재 정보 안내, 편집 중 바뀐 필드 표시, 제출 확인 체크, 자료 전달 메모, 제출 기록.
   - 관리자: 기관별 제출한 필드를 기존값과 비교, 최종 확인 메모 입력 및 검토 처리.
4) tests/profile-approval.test.mjs 신규, package.json 2.9.3.
