돌봄지음 호남 v2.9.1 — 관리자 검색 보완판
2026-11-20

1. 검색어 개선
  - '고운정 요양원' -> '나주고운정요양원'처럼 띄어쓰기 다른 등록명 검색
  - '나주 요양원' -> '나주시'와 '요양원'을 조합한 검색
  - 보호자 참고 기본명단과 관리자 서버 검색 모두 적용

2. 관리자 검색 서버 장애 시
  - 공개 기본명단(과거 공공자료의 기관명·유형·지역·자료 기준일)만 읽기전용 표시
  - 계약·승인·입금·기관 ID 관리 기능은 실제 서버가 살아있을 때만 사용 가능
  - 관리 DB 검색 자체의 500 오류 원인은 아직 미확정; Netlify > Cloud compute > Functions > api 로그 확인 필요
  - 함수 로그에 firebase-credentials-missing / firebase-credentials-malformed 등 원인 코드 표시
  - Netlify 환경변수 FIREBASE_SERVICE_ACCOUNT_JSON 설정 여부(값은 공개하지 말 것) 확인

3. 안전성
  - 기존 기관 DB와 운영 자료를 자동으로 수정하지 않음
  - 임의의 승인·계약·광고 여부를 생성하지 않음
  - 시험 브랜치 dolbom-v25-test에서만 먼저 확인

4. GitHub 업로드
  - '변경파일만' ZIP은 압축 해제 후 아래 상대경로 그대로 기존 파일을 교체
    site/app.js
    site/index.html
    netlify/functions/_shared/admin-search.mjs
    netlify/functions/_shared/core.mjs
    tests/admin-search.test.mjs
    package.json
  - '전체시험본' ZIP은 시험용 배포 폴더 전체
  - 운영 브랜치 병합/Publish deploy 금지

5. 확인 요령
  - 사이트 Ctrl+Shift+R 새로고침
  - 관리자 화면에서 고운정 요양원 입력 후 Enter
  - 실제 관리 서버가 작동하면 기관 선택·편집 목록
  - 서버 장애가 남아 있으면 [참고용 기본명단]이 뜨며 편집 불가

코드 검사: npm run check 성공, npm test 69개 통과.
단, 운영 서비스 계정에 접근할 수 없으므로 서버 연결 성공은 보장하지 않음.
